Quick experiment
  1. In the editor, write System.out.println("Hello, Java!"); inside the main method.
  2. Press the editor's Run button and look for Hello, Java! in its output panel.
  3. Change the message to Namaste! and run again.
  4. Remove a semicolon or misspell a keyword to see a compiler error; then fix the code and run again.

The embedded editor is a third-party online service. If it does not load in the embedded panel, use “Open editor in a new tab.” Avoid entering passwords, API keys, or private code.
