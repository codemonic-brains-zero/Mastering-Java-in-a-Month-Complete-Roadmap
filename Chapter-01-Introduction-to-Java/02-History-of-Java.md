# History of Java

## 1. Overview

Java is a general-purpose programming language and platform developed at Sun Microsystems. Its development began in the early 1990s, it was publicly announced in 1995, and Java 1.0 was released in January 1996.

Java's history is easiest to understand as a sequence of stages: the Green Project, the Oak language, the move toward networked software and the Web, the public announcement of Java, and its later evolution.

## 2. The Green Project (1990–1991)

Sun Microsystems started an exploratory project to investigate software for the next generation of consumer electronic devices. The team included James Gosling, Patrick Naughton, and Mike Sheridan.

The work became known as the **Green Project**, and the engineers involved were often called the **Green Team**. The project explored software for devices such as handheld controllers and other embedded consumer electronics, where different hardware designs made portability important.

### Why this project mattered

- Consumer devices could use different processors and hardware architectures.
- Software needed to work reliably in environments with limited resources.
- The team was interested in software that could be moved between devices without rewriting it for every machine.
- These goals helped shape Java's later emphasis on portability, reliability, and security.

## 3. Early Names: GreenTalk and Oak

You may encounter more than one name in accounts of Java's early development.

- **GreenTalk** and the `.gt` extension are mentioned in some secondary educational sources as an early name and file extension.
- **Oak** is the best-documented early name in Java's commonly cited history. James Gosling named it after an oak tree associated with his office.
- The language was developed as part of the Green Project.

**Important:** Avoid saying that GreenTalk was Java's only or universally accepted first name. Historical summaries do not always describe the earliest naming stages consistently; Oracle's official history emphasizes the Green Project and Oak.

## 4. Why Was Oak Renamed Java?

The name **Oak** could not be used for the public product because it was already associated with another company's trademark. The team therefore chose a new name.

The name **Java** was inspired by Java coffee, associated with the Indonesian island of Java. Java is a name, not an acronym.

## 5. From Consumer Devices to the World Wide Web

The original project focused on consumer electronics, but the team recognized that the language's portability and network-friendly design could also be useful for software distributed over networks.

During the early-to-mid 1990s, the World Wide Web was growing rapidly. Java's ability to run compiled code on different systems made it attractive for networked applications. The HotJava browser demonstrated Java technology in the context of the Web, and Java attracted broad attention when Sun announced it publicly in 1995.

**Historical distinction:** The Web was not created by Java. Java became publicly known during the Web's early growth, and the Web gave Java an important use case.

## 6. Important Milestones

| Year / Date | Milestone |
|---|---|
| 1990–1991 | Sun's exploratory work develops into the Green Project. |
| Early 1990s | The team develops Oak for software intended for consumer devices. |
| 1994 | Work on a Web-oriented browser, later known as HotJava, helps connect Java with the Web. |
| May 1995 | Sun publicly announces Java. |
| 23 January 1996 | Java 1.0 / JDK 1.0 is released. |
| 1998 | Java 2, also known as J2SE 1.2, marks an important platform milestone. |
| 2004 | Java 5 introduces major language features, including generics and enhanced for-loops. |
| 2006 | Sun announces plans to make much of Java available as open-source software through OpenJDK. |
| 2010 | Oracle completes its acquisition of Sun Microsystems and becomes Java's steward. |
| 2017 | Java 9 begins the six-month feature-release cadence. |
| 2018 onward | Long-Term Support (LTS) releases become important planning points for many users and organizations. |

Dates in historical timelines can refer to different events—for example, a project beginning, a language being renamed, a public announcement, or a product release. These should not be treated as the same event.

## 7. James Gosling and the Green Team

**James Gosling** is widely known as the father of Java because of his central role in designing the language. Patrick Naughton and Mike Sheridan were also key members of the early project.

Java was a team effort developed at Sun Microsystems, rather than a language created by one person in isolation.

## 8. Java and the Web: What Actually Happened?

Java became well known in the 1990s partly because browsers and networked software created a practical setting for portable code.

Keep these points separate:

- The World Wide Web already existed before Java's public announcement.
- Java was announced publicly in 1995.
- Java 1.0 was released in 1996.
- Early browsers supported Java applets, which could run Java code inside a browser environment.
- Browser applets are now obsolete in modern browsers, but Java continues to be used for many other kinds of software.

## 9. Key Terms

- **Sun Microsystems:** The company where Java was developed.
- **Green Project:** Sun's early project exploring software for consumer electronic devices.
- **Green Team:** The engineers who worked on that project.
- **Oak:** The early name most commonly associated with the Java language.
- **Java:** The name adopted before the language's public launch.
- **HotJava:** An early Web browser associated with demonstrating Java technology.
- **JDK 1.0:** The first major public Java development kit release, dated 23 January 1996.

## 10. Common Misconceptions

1. **“Java and the Web started at the same time.”**  
   Not exactly. The Web predates Java's public announcement; Java became prominent as the Web was growing.

2. **“Java was originally designed only for websites.”**  
   No. Its early goal was software for consumer electronic devices. Web use became important later.

3. **“Java is an acronym.”**  
   No. Java is a name, inspired by Java coffee.

4. **“Java 1.0 was released in 1995.”**  
   The public announcement was in 1995; Java 1.0 / JDK 1.0 was released on 23 January 1996.

5. **“GreenTalk is the only accepted name for the earliest version.”**  
   Some secondary sources mention GreenTalk and `.gt`, but commonly cited official histories emphasize Oak. Describe the naming history with this distinction.

## 11. Quick Revision

- Java's development began in the early 1990s at Sun Microsystems.
- The Green Project explored software for consumer electronic devices.
- Oak is the best-documented early name for the language.
- Oak was renamed Java before the public launch.
- Sun announced Java in May 1995.
- Java 1.0 / JDK 1.0 was released on 23 January 1996.
- The Web helped Java gain attention, but Java did not create the Web.
